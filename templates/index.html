📖 Detailed Theory & Mathematical Derivation

1. Earth-Centered, Earth-Fixed (ECEF) Coordinate System

The ECEF system is a 3-dimensional Cartesian coordinate system (X, Y, Z) that rotates synchronously with the Earth. Its geometric center (0, 0, 0) is fixed precisely at the Earth's center of mass.

  • Z-axis: Points northward along Earth's true rotational axis (Conventional Terrestrial Pole).
  • X-axis: Lies in the equatorial plane, intersecting the Prime Meridian (0° longitude) at the equator.
  • Y-axis: Completes the right-handed orthogonal system, pointing towards 90° East longitude at the equator.

2. WGS-84 Reference Ellipsoid

Because the Earth bulges at the equator due to centrifugal force, it is modeled as an oblate spheroid rather than a perfect sphere under the World Geodetic System 1984 (WGS-84) standard.

It is defined by two primary geometric parameters: the semi-major equatorial radius (a = 6,378,137 m) and flattening (f ≈ 1 / 298.257). Transforming ECEF Cartesian coordinates (X, Y, Z) maps the receiver's position onto this mathematical reference ellipsoid.

3. Mathematical Derivation of 3D Trilateration Equations

To find the unknown receiver position vector (X, Y, Z) and receiver clock offset bias b, we formulate simultaneous equations using signals received from 4 visible satellites.

Step A: True Euclidean Distance (Geometric Distance via Pythagorean Theorem)
di = √[ (X - xi)2 + (Y - yi)2 + (Z - zi)2 ]

The true straight-line distance di between a receiver position (X, Y, Z) and satellite i at coordinates (xi, yi, zi) is derived by applying the Pythagorean theorem step-by-step from 1D to 3D space:

  • 1D Distance on a Line: The linear distance along a single axis (e.g., the X-axis) between two points is simply the absolute difference: Δx = (X - xi).
  • Extending to a 2D Plane: If we look at the horizontal XY plane, the straight-line distance (hypotenuse) across the plane forms a right-angled triangle with base Δx and height Δy = (Y - yi). By the Pythagorean theorem (c2 = a2 + b2), the 2D planar distance is √[ (X - xi)2 + (Y - yi)2 ].
  • Extending to 3D Space: To account for height/altitude, we treat this 2D planar distance as the base of a new vertical right-angled triangle. The vertical height is the difference along the Z-axis: Δz = (Z - zi). Applying the Pythagorean theorem a second time between this base and height yields the final 3D Euclidean distance formula: di = √[ (X - xi)2 + (Y - yi)2 + (Z - zi)2 ].
Step B: Accounting for Receiver Clock Bias
Pi = C × Δti = di + b

Radio signals travel at the speed of light C ≈ 299,792,458 m/s. Multiplying the measured signal travel time Δti by C gives the pseudorange Pi. It is called a "pseudo" range because consumer receiver clocks are not synchronized with atomic satellite clocks, introducing a clock error term b (expressed in meters of equivalent distance).

Step C: Assembling the 4-Satellite Simultaneous Equations
P1 = √[ (X - x1)2 + (Y - y1)2 + (Z - z1)2 ] + b
P2 = √[ (X - x2)2 + (Y - y2)2 + (Z - z2)2 ] + b
P3 = √[ (X - x3)2 + (Y - y3)2 + (Z - z3)2 ] + b
P4 = √[ (X - x4)2 + (Y - y4)2 + (Z - z4)2 ] + b

Because there are 4 unknown variables to solve for—three spatial position coordinates (X, Y, Z) and one clock bias term b—exactly four independent satellite equations are required to find a unique, unambiguous receiver position.
